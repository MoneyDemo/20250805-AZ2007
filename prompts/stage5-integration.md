# 階段五：整合與優化 PROMPT

## 任務概述
進行最終整合、效能優化、部署準備，並完成專案交付前的最後檢查與文件整理。

## 具體指令

1. 切換到新分支 `feature/integration-optimization`
2. 系統整合與測試：
   - 整合所有功能分支到主分支
   - 解決任何合併衝突
   - 執行完整的迴歸測試
   - 驗證所有功能在整合後仍正常運作
3. 效能優化：
   - 分析並優化 API 回應時間
   - 實作更聰明的快取策略
   - 優化前端資源載入順序
   - 減少不必要的重複請求
4. 使用者體驗優化：
   - 改善 Loading 狀態與過渡動畫
   - 優化錯誤訊息顯示
   - 增強鍵盤導航支援
   - 改善無障礙功能 (Accessibility)
5. 安全性加強：
   - 實作請求頻率限制
   - 加強輸入驗證與清理
   - 檢查並修復潛在的安全漏洞
   - 實作適當的 HTTP 安全標頭
6. 監控與日誌：
   - 實作基本的應用程式日誌記錄
   - 加入錯誤追蹤機制
   - 監控 API 呼叫頻率與回應時間
7. 部署準備：
   - 建立生產環境設定檔
   - 最佳化靜態檔案服務
   - 準備部署說明文件
   - 建立健康檢查端點
8. 最終文件整理：
   - 完善 README.md：確保所有圖表與說明正確
   - 更新 API 文件：加入所有端點與範例
   - 建立部署指南：包含生產環境設定步驟
   - 整理架構文件：確保與實際實作一致
9. 品質保證檢查：
   - 執行完整的測試套件
   - 檢查程式碼覆蓋率報告
   - 進行手動 UI/UX 測試
   - 驗證跨瀏覽器相容性
10. 專案交付準備：
    - 建立專案展示簡報或影片
    - 準備 DEMO 資料與測試案例
    - 整理開發歷程與技術決策記錄
    - 建立專案總結報告
11. 版本標記與發布：
    - 標記穩定版本 (如 v1.0.0)
    - 建立發布說明 (Release Notes)
    - 壓縮並打包交付檔案
12. 分步提交並推送：
    - 優化、整合、文件更新分別提交
    - 提交訊息範例：`perf: optimize API response time and implement smart caching`
    - 最終提交：`release: prepare v1.0.0 with complete features and documentation`

## 驗收項目
- 所有功能整合完成且穩定運作
- 效能達到預期標準 (API 回應 < 2秒)
- 安全性檢查通過無高風險漏洞
- 使用者體驗流暢且直觀
- 文件完整且準確反映實際功能
- 程式碼品質達到生產等級標準
- 專案可順利部署到目標環境
- 交付物件完整且易於理解
