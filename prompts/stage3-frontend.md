# 階段三：前端介面開發 PROMPT

## 任務概述
建立響應式前端使用者介面，整合 Bootstrap 5 與 JavaScript，實作股票查詢與自動刷新功能。

## 具體指令

1. 切換到新分支 `feature/frontend-ui`
2. 建立 HTML 模板 (`templates/`)：
   - `base.html`：基礎模板，包含 Bootstrap 5 CDN、FontAwesome 圖示、主題切換功能
   - `index.html`：首頁模板，包含股票搜尋表單與結果顯示區域
   - `error.html`：錯誤頁面模板，顯示友善錯誤訊息
3. 實作 CSS 樣式 (`static/css/main.css`)：
   - 自定義樣式與主題變數
   - 深色/淺色模式樣式定義
   - 響應式設計調整
   - 股票資訊顯示卡片樣式
4. 實作核心 JavaScript (`static/js/`)：
   - `main.js`：主要應用程式邏輯、主題切換、事件綁定
   - `stock-display.js`：股票資料顯示、API 呼叫、自動刷新機制
5. 實作前端功能：
   - 股票代碼輸入與即時驗證
   - AJAX API 呼叫與錯誤處理
   - 股票價格資訊動態顯示
   - 自動刷新頻率設定 (10秒/1分鐘/5分鐘/手動)
   - 深色/淺色模式切換與本地儲存
6. 優化使用者體驗：
   - Loading 狀態指示器
   - 輸入提示與自動補全
   - 錯誤訊息友善顯示
   - 鍵盤快捷鍵支援 (Enter 送出)
7. 實作響應式設計：
   - 桌面版、平板、手機版佈局適配
   - 觸控友善的操作介面
   - 適當的字型大小與間距
8. 整合測試：
   - 手動測試各項前端功能
   - 跨瀏覽器相容性檢查
   - 響應式設計測試
9. 效能優化：
   - 壓縮 CSS 與 JavaScript
   - 圖片最佳化
   - 減少不必要的 API 請求
10. 分步提交並推送：
    - 每個功能元件完成後獨立提交
    - 提交訊息範例：`feat: implement responsive stock search interface with auto-refresh`

## 驗收項目
- 前端介面完整實作並符合設計要求
- 響應式設計在各裝置上正常顯示
- 所有 JavaScript 功能正常運作
- 深色/淺色模式切換功能完整
- 自動刷新機制可正確設定與執行
- 錯誤處理與使用者提示友善明確
